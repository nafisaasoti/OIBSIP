# Google Play Store Data Analysis

## Project Overview
This project analyzes Google Play Store applications and user reviews using Python. It explores app categories, ratings, installations, size, pricing, and customer sentiment.

## Objectives
- Clean and preprocess app and review datasets.
- Analyze app categories and ratings.
- Study the relationship between app size and installations.
- Compare free and paid applications.
- Perform sentiment analysis on user reviews.
- Generate visualizations and meaningful insights.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- VADER Sentiment Analysis
- Plotly
- Jupyter Notebook

## Dataset
Google Play Store Apps dataset from Kaggle:

https://www.kaggle.com/datasets/lava18/google-play-store-apps

The project uses app information and user review datasets.

## Project Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Category and rating analysis
4. App size and installation analysis
5. Free and paid app analysis
6. User review sentiment analysis
7. Data visualization
8. Insights and conclusion

## Project Outputs
- Cleaned app dataset
- Reviews with sentiment scores
- Sentiment analysis by category
- Interactive Plotly visualization
- Charts and graphs saved in the Screenshots folder

## Conclusion
This project provides insights into Google Play Store trends, app popularity, pricing, ratings, and user opinions. The analysis can help developers better understand app-market patterns and user satisfaction.
