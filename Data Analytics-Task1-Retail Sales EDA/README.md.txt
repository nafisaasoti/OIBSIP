# Retail Sales Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on retail sales data using Python. The aim is to understand sales trends, customer behavior, and product category performance.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The dataset contains 1,000 retail transactions with information about transaction dates, customer IDs, gender, age, product categories, quantity, price per unit, and total amount.

## Analysis Performed
- Checked dataset shape, data types, missing values, and duplicate records.
- Calculated descriptive statistics.
- Visualized monthly sales trends.
- Analyzed sales by gender and customer age.
- Compared revenue across product categories.
- Created a correlation heatmap.
- Explored additional relationships in the sales data.

## Key Findingss
The analysis explores monthly sales patterns, customer demographics, and revenue differences across product categories. The charts help identify trends and relationships in the dataset.

## Conclusion
Exploratory Data Analysis helps businesses understand their sales performance and customer purchasing behavior. The findings can support better inventory planning, targeted marketing, and data-driven business decisions.

## How to Run
1. Install Python and Jupyter Notebook.
2. Install the required libraries: pandas, matplotlib, and seaborn.
3. Keep the dataset inside the `Dataset` folder.
4. Open `OIBSIP_Task1_Retail_Sales_EDA.ipynb` in Jupyter Notebook.
5. Run the notebook cells in order.
